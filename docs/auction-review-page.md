# Подборка недвижимости

`https://omnizen.netlify.app/lots/` — самостоятельная страница с результатами
расчёта 15 лотов. `/lots/flow/` объясняет порядок отбора.

HTML в `public/lots/` создаётся проектом `auc` из сохранённой публикации.
Vite копирует эти страницы в `dist/lots/`, Netlify публикует их вместе с Omnizen.
Основное приложение, его авторизация и функции от этой страницы не зависят.

Публикуется датированный снимок, а не сборщик или база. Закрытые исходники,
локальные PDF, фотографии, пароли и сессии в него не входят. В карточках
доступны внешние ссылки на источники и контуры. Ответы читателя скачиваются
в JSON для последующего импорта в `auc`; серверного сохранения здесь нет.

После окончания срока проверки браузер убирает актуальный вывод и денежные
показатели карточки. Дату публикации видно в шапке. Страницы доступны по ссылке
без входа; запрет индексации не является ограничением доступа.

Для обновления после нового расчёта из папки `auc`:

```powershell
./scripts/Publish-Parents.ps1 -Publish
```

Без `-Publish` команда только готовит HTML в `public/lots/` соседнего проекта
Omnizen. С `-Publish` она проверяет рабочее дерево, запускает `npm run check`,
коммитит только два HTML-файла и отправляет их в `master`. Публикацию выполняет
существующий автодеплой Netlify. Другие изменения команда не включает.
